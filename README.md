# BFviaggi - Agenzia di Viaggi Online

## 📝 Descrizione

**BFviaggi** è un sito web moderno e responsivo di un'agenzia di viaggi specializzata nell'organizzazione di viaggio internazionali. La piattaforma offre ai clienti la possibilità di scoprire e prenotare fantastiche destinazioni turistiche in tutto il mondo.

## ✨ Funzionalità Principali

### 🏠 Home Page
- **Carosello Interattivo**: Presenta le principali destinazioni di viaggio con immagini affascinanti e descrizioni accattivanti
- **Destinazioni Disponibili**:
  - 🗽 **New York** - "La grande mela, la città che non dorme mai"
  - 🇬🇧 **Londra** - "Città centro commerciale, bancario e culturale fra i maggiori del mondo"
  - 🇫🇷 **Parigi** - "La Città della Luce, rinomata per i suoi monumenti e le sue attrazioni iconiche"

### 🧭 Navigazione
- **Navbar Sticky**: Barra di navigazione sempre visibile durante lo scorrimento
- **Menu Dropdown**: Accesso facile alle diverse destinazioni di viaggio
- **Logo Brandizzato**: Logo ufficiale dell'agenzia BFviaggi

### 📋 Sezioni Principali
- **HOME**: Pagina d'accoglienza con carosello principale
- **VIAGGI**: Menù a discesa con le destinazioni disponibili
- **RECENSIONI**: Feedback e testimonianze dei clienti
- **NEWSLETTER**: Iscrizione per ricevere offerte esclusive e aggiornamenti

## 🛠️ Tecnologie Utilizzate

- **HTML5**: Struttura semantica del sito
- **CSS3**: Stili personalizzati e responsive
- **Bootstrap 5.3.3**: Framework CSS per un design moderno e responsivo
- **JavaScript**: Interattività e dinamicità (incluso tramite Bootstrap)

## 📱 Caratteristiche Responsive

Il sito è completamente responsive e si adatta perfettamente a:
- 💻 Desktop
- 📱 Tablet
- 📲 Smartphone

- **Interfaccia Intuitiva**: Facile navigazione per gli utenti

- **Overlay Dinamico**: Immagini di sfondo con overlay semi-trasparente per migliorare la leggibilità del testo

## 🚀 Come Utilizzare

1. Visita il sito all'indirizzo: [fabiobl77.github.io/AgenziaViaggi](https://fabiobl77.github.io/AgenziaViaggi/)

3. Accedi alle sezioni VIAGGI per maggiori dettagli
